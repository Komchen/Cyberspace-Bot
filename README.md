# Cyberspace-Bot
The official discord bot for the Cyberspace club at Slippery Rock University


other users:
install dependencies:
python -m pip install -r requirements.txt
python -m pip install --upgrade google-api-python-client google-auth-httplib2 google-auth-oauthlib

If the google calendar token expires: go to google api, replace the credentials.json with new secret. then delete calendar_token.json then run bot, it will prompt authorization : nadiarae mail then itll create new token.
